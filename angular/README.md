# Projets Angular — ESTIAM

## [Gestion de cours](gestion-cours/)

Application de consultation de cours avec un espace d’administration pour gérer
leur publication. Le projet a été importé depuis `projet-estiam-angular` et
dispose désormais d’une configuration Docker Compose autonome.

Depuis `angular/gestion-cours/`, lancez `docker compose up --build`, puis ouvrez
[localhost:4000](http://localhost:4000/). Les détails de lancement et d’arrêt
figurent dans le [README du projet](gestion-cours/README.md).
